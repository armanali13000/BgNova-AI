# BgNova AI

**BgNova AI** is a modern AI background remover and browser-based image editor built with React and Vite. It helps users upload images, crop, erase, repair, preview backgrounds, and export clean transparent PNG, JPG, or WEBP files.

🌐 **Live demo:** [https://bgnovaai.vercel.app/](https://bgnovaai.vercel.app/)

---

## ✨ Features

- AI-ready background removal interface
- Upload JPG, PNG, and WEBP images
- Crop-first editing workflow
- Manual erase and repair tools
- Magic erase and color removal controls
- Transparent checkerboard preview
- White, black, transparent, and custom background previews
- Export as PNG, JPG, or WEBP
- Responsive landing page and editor UI
- SEO-ready metadata, sitemap, robots.txt, and schema markup
- Google Search Console compatible

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/armanali13000/BgNova-AI.git
cd BgNova-AI
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run locally

```bash
npm run dev:vite
```

Open:

```txt
http://localhost:3010/
```

### 4. Build for production

```bash
npm run build
```

The production files are generated in:

```txt
dist/
```

---

## 🌍 Deployment

This project is deployed on Vercel.

Recommended Vercel settings:

```txt
Framework Preset: Vite
Install Command: npm install
Build Command: npm run build
Output Directory: dist
```

The project also includes a `vercel.json` file for deployment configuration.
